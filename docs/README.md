# Research and model testing

This directory contains non-publishable research artifacts and evaluation results.
The model comparison corpus is organized under [model-comparisons](model-comparisons),
including local-model baselines, remote-provider runs, usage logs, quality scores,
readability measurements, and comparison dashboards.

Executable pipeline code remains under [automation](../automation): the pipeline
package, prompts, pipeline definitions, scoring implementation, and automated tests.
