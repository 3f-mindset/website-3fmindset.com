# Steady Burn Week 5: Expose Limiting Beliefs

- **Phase:** 1 — Identify the Blade
- **Release:** 2026-01-30

## Core aim

This seed translates the expose limiting beliefs curriculum theme into one direct weekly practice. The work must be concrete, honest, and measurable—not another idea left in a notebook.

## Empowering action

Write one limiting belief, gather contrary evidence, and replace it with a truthful battle cry.

## Worksheet outcome

Name the current reality, the standard for this week, the first action, and the proof that it was completed.

## Journal prompt

> How would I behave this year if I no longer believed this old story?
