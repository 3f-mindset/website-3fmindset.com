# Steady Burn Week 2: Unearth Your Core Values

- **Phase:** 1 — Identify the Blade
- **Release:** 2026-01-09

## Core aim

This seed translates the unearth your core values curriculum theme into one direct weekly practice. The work must be concrete, honest, and measurable—not another idea left in a notebook.

## Empowering action

Choose three to five non-negotiable values and define what each requires in action.

## Worksheet outcome

Name the current reality, the standard for this week, the first action, and the proof that it was completed.

## Journal prompt

> Where are my actions aligned or misaligned with my values?
